Format du fichier

Un fichier CSV en UTF-8, avec le point-virgule comme séparateur, et cette ligne d'en-tête :

{{ entete }}
  • date_mise_service : au format AAAA-MM-JJ ou JJ/MM/AAAA ;
  • type : le libellé du type d'équipement, par exemple « Presse hydraulique » ;
  • zone : le code de la zone, par exemple « A1 ».

Chaque ligne valide crée un équipement en service. Une ligne invalide est écartée sans bloquer les autres, et le rapport indique pourquoi.
